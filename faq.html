Frequently Asked Questions

Find answers to common questions about this site and my work

General Questions

This site is built using modern web technologies including HTML5, CSS3, and vanilla JavaScript. The backend uses Node.js with Express for serving content, and the Marked library for parsing markdown blog posts. The design system uses CSS custom properties for easy theming and customization.

Adding new blog posts is simple! Just create a new markdown (.md) file in the posts/ directory, then add an entry to the posts/posts.json file with the post metadata (title, date, description, etc.). The blog system will automatically pick up the new post and display it on the blog page.

Absolutely! The entire design system is built using CSS custom properties (variables) defined at the top of css/styles.css. You can easily change colors, spacing, typography, and more by modifying these variables. The design will automatically update throughout the entire site.

Technical Questions

First, make sure you have Node.js installed. Then run npm install to install dependencies, and npm start to start the development server. The site will be available at http://localhost:3000.

Yes! The site is fully responsive and works beautifully on all devices. The design uses modern CSS techniques like CSS Grid and Flexbox, along with media queries to ensure a great experience on mobile phones, tablets, and desktop computers.

Of course! This is a template designed to be customized and used for your own projects. Feel free to modify the content, design, and functionality to suit your needs. Just update the text, colors, and add your own blog posts to make it your own.

Design Questions

The design is inspired by modern web design trends including glassmorphism, vibrant gradients, and smooth animations. The dark theme with colorful accents creates a premium, professional look while maintaining excellent readability. The goal was to create something that feels both cutting-edge and timeless.

The site currently uses the Inter font from Google Fonts. To change it, update the @import statement at the top of css/styles.css with your preferred Google Font, then update the --font-family CSS variable to use your new font.
